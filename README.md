# 🌱 Toddler Growth Tracker

Track your toddler’s height and weight using official **WHO Child Growth Standards** (0–24 months).

A simple and beautiful React Native app that calculates **Z-scores**, **percentiles**, and shows interactive growth charts.

---

## ✨ Features

- Official **WHO LMS data** (0–24 months)
- Weight-for-Age & Length/Height-for-Age calculation
- Instant **Z-score** and **Percentile** results
- Clear growth status (Normal / Low / High / Severely Low or High)
- Interactive growth charts (3rd, 50th, 97th percentiles)
- Measurement history saved locally on device
- Clean and parent-friendly UI
- Fully offline

---

## 📱 Screens

| Screen     | Description                                      |
|------------|--------------------------------------------------|
| **Track**  | Enter age, gender, weight & height → get results |
| **Charts** | View WHO growth curves for boys and girls        |
| **History**| See all previously saved measurements            |

---

## 🛠️ Tech Stack

- **React Native** + **Expo**
- **React Navigation** (Bottom Tabs)
- **react-native-chart-kit** (Graphs)
- **AsyncStorage** (Local history storage)
- **expo-linear-gradient**
- Official **WHO LMS parameters**
